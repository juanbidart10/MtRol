# Instalación rápida

1. Copiar el ZIP en `C:\FoundryVTT\Data\systems\mtrol`.
2. Descomprimirlo desde esa carpeta conservando la estructura interna.
3. El resultado debe crear `assets\ui\chat\cards-premium\v4` y `docs\cards-premium-v4`.
4. Integrar el registro y el renderer para que usen la ruta `v4` y las coordenadas de `layout.json`.
5. No borrar `v3` hasta completar la comparación visual y funcional dentro de Foundry.

El ZIP no modifica código, `system.json`, tests ni archivos existentes por sí solo.
