# MtRol
Nuevo Sistema De Foundry

## Modulos opcionales recomendados

MtRol Core funciona sin modulos externos. Si no estan activos, las reglas, hojas y flujo base siguen disponibles, pero algunas funciones visuales se reducen.

- Dice So Nice: dados visuales.
- Sequencer: FX visuales.
- JB2A: libreria de animaciones para FX.
- 3D Canvas: soporte experimental, no requerido.
