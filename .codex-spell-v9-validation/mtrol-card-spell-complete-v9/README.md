# Asset completo de HECHIZO

`assets/ui/chat/cards-premium/v9/spell.png` es un único PNG RGBA de 720 × 1440. Se renderiza a 303 × 606.

Ya contiene fusionados:

- marco y textura;
- medallón y símbolo violeta;
- placa y texto `HECHIZO`;
- separador y texto `RESULTADO`;
- círculo rúnico;
- panel y texto `DESGLOSE DE DADOS`;
- tres guías para filas de dados;
- texto `MODIFICADORES`;
- cuatro cubículos vacíos.

El renderer sólo debe superponer nombre, fórmula, total, dados reales y valores de modificadores. No debe volver a crear ninguno de los elementos estáticos mediante HTML, SVG, pseudo-elementos o CSS.
